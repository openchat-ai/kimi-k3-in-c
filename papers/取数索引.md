## 统计口径

### 数值精度

《计算机科学》的投稿模板与投稿须知均未规定表内数值保留几位小数（模板只要求
"使用的量符合法定计量单位标准"）。本稿因此自定约定，并全文一致执行：

- **不为精确值补零**：恰为整数的量写成整数（`100`、`0`、`77`），不写成 `100.00`、
  `0.00`、`77.00`。补零会让"精确为零"看起来像"测到一个小数"。
- 台账里记几位就写几位，不向上取整显示精度：`bottleneck_bound.tsv` 存 `191.6`、
  `77.5`、`64.3`，正文即写 191.6、77.5、64.3，不补成 `191.60`。
- 测量值末位恰好是 `0` 的（`24.40`、`28.60`、`1.60`）保留，那是有效位而非补零。
- 计数（缓存槽位）与带宽档位（379 MB/s、1.5 GB/s）保持整数。
- 恒等式 C2 的偏差按 3 位小数给（0.021 / 0.017），与台账的两位有效数字分辨率相当；
  `E(1) = 0.9927` 等拟合量保留 4 位，因其本身是拟合结果而非原始计数。

### 跨度与噪声底的口径（务必按此重算）

同一篇稿件里出现过两个"跨度"，分母不同却未声明，导致过一次错误的直接比较。
现统一约定：

- **极差比 = (最大值 − 最小值) / 最小值**。30 次运行的 80.8% 由此得出。
- **单配置噪声底**取 `docs/data/replication.tsv` 三次连做（14.67 / 14.78 / 20.14 s），
  按 (最大值 − 最小值)/均值 = **33.1%**；若按极差/最小值则为 **37.3%**。
- **两者比较时必须同口径**。正文 4.4 节曾把 32 GB 段的 10.2% 与 33.1% 直接相比并称
  "三分之一"，因分母不同而不成立；同口径下应为 10.2% 对 37.3%。
- CV 一律用样本标准差除以均值（30 次运行为 12.20 / 90.82 = 13.43%）。

### 最小可检测效应

最小可检测效应按

```
MDE(n) ≈ (t_{0.975,2n−2} + t_{0.80,2n−2}) · CV · √(2/n)
```

计算，α = 0.05 双侧、功效 0.80。CV 取主机 B 那 30 次运行的 13.43%——**该值含配置与版本差异**，
只用于平面间分辨率的对比，不用于判定任何单次运行的墙钟差；主机 A 的单配置重复性为 33.1%。
样本量反解按 Cohen's d = 0.034、同样的 α 与功效。

## 两个必须连着读的口径

1. **两台主机不可混用。** 主机 A 的源层是 3.2 GB/s NVMe，主机 B 是约 60—85 MB/s 机械盘加
   1.9 GB/s NVMe。两者的字节数不得互相代入。
2. **每词元字节不是同一口径。** 主机 A 的会话为 N = 8；主机 B 每次运行交付 216.66 GB
   （主干 140.16 + 专家 76.51，三词元合计），含主干且按会话计，**不可与主机 A 的
   B_full(8) = 206.64 GB 或 25.83 GB/词元同框相除**——那会得到 −4.85% 的假"负命中率"。
